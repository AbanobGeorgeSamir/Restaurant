# Restaurant Laravel MongoDB Project

This Laravel application is configured for MongoDB Atlas and prepared for deployment to Vercel (PHP runtime).

IMPORTANT: Do NOT commit production secrets (like the full MONGODB_URI). Set them in the Vercel Project Environment Variables.

Quick setup (local):

1. composer install
2. cp .env.example .env
3. Fill in .env values or set the equivalent secrets in your environment
4. php artisan key:generate
5. php artisan migrate (only if migrations are compatible with MongoDB and ext-mongodb is installed)

Connecting to MongoDB Atlas:

- Provide the MONGODB_URI in the environment (Vercel Dashboard > Project > Settings > Environment Variables).
  Example: MONGODB_URI="mongodb+srv://user:password@cluster0.nbkcycm.mongodb.net/restaurant?retryWrites=true&w=majority"
- Ensure DB_CONNECTION=mongodb and DB_MONGODB=restaurant.

Vercel production notes:

- Use APP_ENV=production and APP_DEBUG=false
- Set APP_URL to your Vercel domain (e.g. https://your-domain.vercel.app)
- Set the following environment variables in Vercel:
  - MONGODB_URI  (full connection string)
  - APP_KEY       (generated by php artisan key:generate)
  - Any mail or AWS credentials needed in production
- Recommended session/cache for serverless:
  - SESSION_DRIVER=cookie (stateless cookies)
  - CACHE_STORE=file or a managed cache (Redis) if you need persistence
- The Vercel PHP runtime must include the ext-mongodb extension. If using the default @vercel/php builder, confirm the runtime supports ext-mongodb or use a custom runtime image.

Building on Vercel:

- Vercel will run composer install during build if configured. See vercel.json for an example build configuration included in this repository.

Security:

- Never put credentials in repository files. Use Vercel environment variables.
